# StudyBoard

Plataforma de **chat + organização de tarefas** para grupos de estudo.

## 📄 Documentação
- 👉 [**PRD — Product Requirements Document**](docs/PRD.md)
- 📋 GitHub Project (acompanhamento): _colar o link do Project aqui_

## Resumo
- Chat em grupo e conversa direta em tempo real, com histórico persistido em **MongoDB (NoSQL)**
- Quadro de tarefas (A fazer / Em andamento / Concluído)
- Transformar mensagens do chat em tarefas
